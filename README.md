# 🤖 AI Mentor - Student Information Management System (SIMS)

A modern, high-performance Student Information Management System (SIMS) built with Android Native (Java), Material 3, and a sleek Glassmorphic Dark UI.

---

## ✨ Features

- 🎨 **Futuristic AI Mentor Dashboard**: Layered Aurora light mesh background, 7-day study streak badge, Bento Grid academic metrics (GPA & credit progress), and interactive AI prompt chips.
- 📚 **BTEC HND Computing Course Management**: Pre-populated with all 16 official Pearson BTEC HND IT units. Supports course listing, dynamic insertion, and deletion.
- 🖼️ **1:1 Avatar Cropping**: Built-in profile photo picker with centered 1:1 square cropping and local storage.
- 🔒 **SHA-256 Password Security**: Cryptographically hashed user passwords for maximum database protection.

## 🛠️ Tech Stack

- **Platform**: Android Native (Java)
- **UI Framework**: Material 3, ConstraintLayout, Glassmorphism
- **Database**: SQLite (SQLiteOpenHelper)
- **Target SDK**: Android 14 (API 36) / minSdk 24
